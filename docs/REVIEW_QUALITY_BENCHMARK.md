# FRI Research Review Quality Benchmark — Issue #19 P2 (synthetic)

P2 measures the usefulness and correctness of a human-facing Research Review Pack.
The included benchmark uses an **independently authored synthetic** truth table,
not results exported from ForexPro Core. It does not prove real source custody,
causal validity, profitability, independent replication or staff time savings.

## Runnable synthetic benchmark

From an installed local FRI source checkout:

    python -m forexpro_ri.cli review demo --out local_data/review-benchmark-demo
    python -m forexpro_ri.cli review benchmark \
      --dir local_data/review-benchmark-demo \
      --labels examples/review_benchmark_labels.json

The labels are explicitly curated for the signed synthetic fixture generated by
review demo. They state each expected procedure outcome and expected Advisor
topic procedure, independently of the report. Every mismatch is counted;
a missing or extra experiment or procedure cannot silently be ignored.

## Metrics emitted

| Metric | Meaning | Failure handling |
| --- | --- | --- |
| procedure_checks | Number of synthetic gold categorical states | Zero/absent labels rejected |
| correct_procedure_statuses | Exact match of FAIL/PASS/NOT_EVALUABLE/UNOBSERVED | Missing/extra statuses rejected |
| categorical_accuracy numerator/denominator | Exact state-level fidelity | Never generalized to real experiments |
| citation_links_checked | Number of sampled evidence links inspected | Reference must match experiment ID + entry SHA-256 + receipt SHA-256 |
| false_citation_links | Identity triples not contained in reviewed synthetic cases | Nonzero fails structural pass |
| missing_expected_review_topics | Annotated research topics omitted by Advisor | Nonempty fails structural pass |
| other_observed_review_topics | Unlabeled research topics | Nonempty requires curator attention |
| scientific/causal/real time flags | Whether scientific validity or actual time benefit is established | Always false in synthetic mode |

The tool separately enforces DESCRIPTIVE_NOT_CAUSAL and all-false authority.
It does not attempt to semantically certify free-form model prose; optional
Ollama prose remains unverified and is excluded from this first benchmark.

## Next human study — not performed in public CI

1. Create a curator-reviewed set of at least 20 heterogeneous synthetic closed
   cases, including repeated failures, incomplete evidence, shared lineages,
   conflicting outcomes, forged citations and deliberate protocol gaps.
2. Give reviewers the same tasks with and without FRI, randomize task order,
   and record analyst time, errors, correct references and unsupported claims.
3. Measure separately: status fidelity, reference coverage, incorrect citation
   count, mistaken independence claims, false causal/profit inferences, and
   task completion time. Do not aggregate these into a synthetic quality score.
4. Only after source-owner-approved closed scientific exports exist, conduct
   an offline private evaluation with an independent researcher and approved
   custody. Never upload actual experiment data or benchmark reports to public CI.
5. Report the full denominator and failures. A 100x claim requires actual paired
   operator time measurements and quality non-inferiority, not synthetic timings.

This synthetic harness is engineering qualification, not production approval.


## Extended 20-case signed synthetic cohort

The minimal one-case signed demo is retained for smoke testing. The extended
cohort exercises 20 explicitly fabricated signed closed experiments, six
expected procedure codes and 120 curator-labeled expected outcome cells.
The input deliberately repeats negative patterns, mixes recorded PASS and FAIL,
includes not-evaluable and missing procedures, and uses one fake source SHA for
all cases so experiment count cannot be mistaken for independent replication.

Run offline:

    python -m forexpro_ri.cli review cohort-demo --out local_data/review-cohort
    python -m forexpro_ri.cli review verify --dir local_data/review-cohort
    python -m forexpro_ri.cli review benchmark \
      --dir local_data/review-cohort \
      --labels examples/review_cohort_gold.json

The cohort signer is a fresh test-only Ed25519 key kept in process memory;
private bytes are not saved. The individual signed synthetic bundles and SQLite
are created in a disposable local temporary directory, then erased. The two
published report files never include raw observations, strategy parameters,
dataset bytes, source credentials or private path strings.

The gold table is stored separately from the generator and does not use
the generated report as an oracle. It is a synthetic curator *fixture*, not
independent scientific validation, a real approved Core result or a measure
of advisor semantic correctness. Reviewers should inspect the gold labels
before treating the benchmark's structural pass as meaningful.

## Private paired operator time-study (descriptive only)

The optional offline study command accepts strictly structured *local* JSON,
without task descriptions, usernames, strategies, timestamps, URLs or source
evidence. The example uses fabricated time entries:

    python -m forexpro_ri.cli review study \
      --input examples/review_time_study_synthetic.json

Each record requires TASK-001-like pseudonymous ID, task order
MANUAL_FIRST/FRI_FIRST, manual_seconds, fri_seconds, six boolean decisions
for answer accuracy, citation accuracy and false independence under each
condition. It rejects additional fields and invalid measurements.

The output provides a paired median and geometric mean speed ratio, total
durations, error counts, task-level quality regressions and an order-balance
check. At least 20 paired tasks and at least five in each order are needed
to flag a self-reported study as eligible for *independent private review*.
The analytic output never says a 100x real improvement is proven, does not
assign causality and does not approve research or broker activity.

For genuine observations, use source_class SELF_REPORTED_PRIVATE_OPERATOR in
a restricted local input file, not a public GitHub commit. Identical tasks,
validated human outcomes, randomized order, preregistered acceptance criteria
and an independent assessor remain prerequisites for reliable inference.
